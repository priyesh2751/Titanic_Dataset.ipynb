Titanic Survival Prediction – Machine Learning Project

About the Project

This project uses Machine Learning to predict whether a passenger survived the Titanic disaster based on passenger information.

Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

Machine Learning Algorithms

* Logistic Regression

Project Workflow

1. Importing required libraries
2. Loading the Titanic dataset
3. Data cleaning and preprocessing
4. Handling missing values
5. Encoding categorical variables
6. Splitting the dataset into training and testing sets
7. Training the Machine Learning model
8. Evaluating model performance

Dataset

The project uses the Titanic dataset containing passenger details such as age, gender, passenger class, and survival status.

How to Run

1. Download the repository.
2. Open the .ipynb file in Google Colab or Jupyter Notebook.
3. Upload Titanic-Dataset.csv.
4. Run all cells.
